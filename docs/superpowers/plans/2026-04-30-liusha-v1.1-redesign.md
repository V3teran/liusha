# liusha v1.1 Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 重构 v1 为「1 流量 → 1 主 ReAct + 同进程嵌套子 ReAct（按 skill 切上下文）」，删除 sniffer 中间层 + traffic_window 切窗，启用启发式前置过滤，hint 双向打通，LLM Client 单例修复并发 bug，统一业界规范命名。

**Architecture:**

```
proxy ─ XADD ─→ Redis Stream (liusha:flow_events)
                 │
                 ▼
       ingestor.Traffic (Stream 消费 + 落库 + 启发式打分)
                 │ score >= 30
                 ▼
       Asynq react queue (单队列)
                 │
                 ▼
       scanner 进程 (asynq.Concurrency=6)
                 │
                 ▼ goroutine
       主 ReAct (mode=traffic, payload={flow_id})
          ├ classify_traffic       (LLM 判流量+漏洞清单)
          ├ spawn_skill(bac, fid)  ─→ 子 ReAct (同进程嵌套, 独立上下文)
          │                           BAC 工具集: read_flow / fetch_creds /
          │                           replay / diff / write_finding / done
          ├ spawn_skill(sqli, fid) ─→ 子 ReAct (v2 添加；本 plan 仅占位)
          ├ get_findings           (查 PG)
          ├ write_fact / write_idea / write_graph (主 LLM 总结)
          └ done                   (DoneValidator 校验业务条件)
       Reviewer (每 5 步, light_provider 评估)
```

**核心约束（决策已锁）：**
- task type 单一 `react`，payload 含 `mode` 区分 traffic/site（site 留 v1.5 扩展口子）
- LLM Client（HTTP）单例，Generator 无状态（tools 在 Generate 时传）
- Reviewer 主 ReAct 启用，子 ReAct 不启用
- DoneValidator + MaxSteps 双兜底（LoopDetector 已砍）
- hint 双向打通：distill hook 写 + 主 ReAct system prompt 自动注入
- graph_node/edge 保留为 attack DAG 语义
- Asynq queue 单一 `agent:react`，保留 `agent:dispatch` 备用
- 主 ReAct 一轮返多个 `spawn_skill` 时 runtime 自动并行（goroutine + WaitGroup）

**Tech Stack:** Go 1.25.6 · sashabaranov/go-openai v1.37 · anthropics/anthropic-sdk-go v1.26 · postgres 17 + pgvector · redis 8 · asynq

```go
// internal/llm/client_pool.go
package llm

import (
    "fmt"
    "sync"

    "github.com/anthropics/anthropic-sdk-go"
    "github.com/anthropics/anthropic-sdk-go/option"
    openai "github.com/sashabaranov/go-openai"
)

type ClientPool struct {
    mu        sync.Mutex
    openai    map[string]*openai.Client
    anthropic map[string]*anthropic.Client
}

func NewClientPool() *ClientPool {
    return &ClientPool{
        openai:    make(map[string]*openai.Client),
        anthropic: make(map[string]*anthropic.Client),
    }
}

func (p *ClientPool) GetOrCreateOpenAI(baseURL, apiKey string) (*openai.Client, error) {
    if apiKey == "" { return nil, fmt.Errorf("openai apikey 必填") }
    key := baseURL + "|" + apiKey
    p.mu.Lock(); defer p.mu.Unlock()
    if c, ok := p.openai[key]; ok { return c, nil }
    cfg := openai.DefaultConfig(apiKey)
    if baseURL != "" { cfg.BaseURL = baseURL }
    c := openai.NewClientWithConfig(cfg)
    p.openai[key] = c
    return c, nil
}

func (p *ClientPool) GetOrCreateAnthropic(baseURL, apiKey string) (*anthropic.Client, error) {
    if apiKey == "" { return nil, fmt.Errorf("anthropic apikey 必填") }
    key := baseURL + "|" + apiKey
    p.mu.Lock(); defer p.mu.Unlock()
    if c, ok := p.anthropic[key]; ok { return c, nil }
    opts := []option.RequestOption{option.WithAPIKey(apiKey)}
    if baseURL != "" { opts = append(opts, option.WithBaseURL(baseURL)) }
    c := anthropic.NewClient(opts...)
    p.anthropic[key] = &c
    return &c, nil
}
```

```go
type Factory struct {
    cfg     config.Config
    pool    *ClientPool
    builder Builder
}

type Builder func(ctx context.Context, cfg config.Config, providerKey string, pool *ClientPool) (Generator, error)

func NewFactory(cfg config.Config) *Factory {
    return &Factory{cfg: cfg, pool: NewClientPool(), builder: BuildProvider}
}

func (f *Factory) For(ctx context.Context, role string) (Generator, error) {
    key := f.resolveProviderKey(role)
    if key == "" { return nil, fmt.Errorf("default_provider 未配置") }
    return f.builder(ctx, f.cfg, key, f.pool)
}

func BuildProvider(ctx context.Context, cfg config.Config, providerKey string, pool *ClientPool) (Generator, error) {
    pc := cfg.Providers[providerKey]
    apiKey := os.Getenv(pc.APIKeyEnv)
    if apiKey == "" { return nil, fmt.Errorf("env %s 为空", pc.APIKeyEnv) }
    switch pc.Type {
    case ProviderTypeOpenAICompat, "":
        cli, err := pool.GetOrCreateOpenAI(pc.BaseURL, apiKey)
        if err != nil { return nil, err }
        return NewOpenAICompat(ctx, providerKey, OpenAICompatConfig{
            BaseURL: pc.BaseURL, Model: pc.DefaultModel, MaxTokens: pc.MaxTokens, APIKey: apiKey,
        }, cli)
    case ProviderTypeAnthropic:
        cli, err := pool.GetOrCreateAnthropic(pc.BaseURL, apiKey)
        if err != nil { return nil, err }
        return NewAnthropic(ctx, providerKey, AnthropicConfig{
            BaseURL: pc.BaseURL, Model: pc.DefaultModel, MaxTokens: pc.MaxTokens, APIKey: apiKey,
        }, cli)
    }
    return nil, fmt.Errorf("provider %q type %q 未知", providerKey, pc.Type)
}
```

### Task 13: 启发式打分

**Files:** Create `internal/heuristic/score.go` + `_test.go`

- [ ] **Step 1: 测试**

测试静态资源 0 分；/admin/ ≥30；/order?uid=1 ≥30；profile only 20-29；POST + cookie ≥30；Threshold() = 30。

- [ ] **Step 2: 实现**

```go
package heuristic

import "strings"

type Flow interface {
    GetMethod() string
    GetURL() string
    GetHeader(key string) string
}

var staticExtensions = []string{".css",".js",".png",".jpg",".jpeg",".gif",".ico",".woff",".woff2",".ttf",".svg",".map"}

var pathSensitive = []struct{sub string; score int}{
    {"/admin/",30},{"/sys/",30},{"/api/admin/",30},
    {"/api/user/",20},{"/profile",20},{"/order/",20},{"/account",20},
}
var idParams = []string{"uid=","user_id=","userId=","account_id=","accountId=","order_id=","orderId="}
var stateChangeMethods = map[string]bool{"POST":true,"PUT":true,"DELETE":true,"PATCH":true}

func Score(f Flow) int {
    url := f.GetURL()
    for _, ext := range staticExtensions {
        if strings.HasSuffix(url, ext) || strings.Contains(url, ext+"?") { return 0 }
    }
    s := 0
    for _, p := range pathSensitive {
        if strings.Contains(url, p.sub) { s += p.score; break }
    }
    for _, k := range idParams {
        if strings.Contains(url, k) { s += 25; break }
    }
    if stateChangeMethods[strings.ToUpper(f.GetMethod())] { s += 10 }
    if f.GetHeader("cookie") != "" || f.GetHeader("authorization") != "" { s += 10 }
    return s
}

func Threshold() int { return 30 }
```
