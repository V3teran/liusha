## 1. 完整认知循环

```
┌──────────────────────────────────────────────────────────────┐
│                        用户下发任务                            │
│  Assignment { targets: ["http://a.com", "http://b.com"] }   │
└────────────────────┬─────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────────┐
│                   系统创建 Task                              │
│  Task A (a.com)  │  Task B (b.com)                         │
│  ├─ task_id: xxx │  ├─ task_id: yyy                        │
│  ├─ assignment_id│  ├─ assignment_id                       │
│  └─ 独立世界模型  │  └─ 独立世界模型                         │
└────────────────────┬────────────────────────────────────────┘
                     ↓
        ┌────────────┴────────────┐
        │                         │
        ↓                         ↓
┌───────────────┐         ┌───────────────┐
│   Task A      │         │   Task B      │
│   世界模型     │         │   世界模型     │
└───────┬───────┘         └───────┬───────┘
        │                         │
        └────────────┬────────────┘
                     ↓
        ┌────────────────────────┐
        │  Lead 黑板 (共享情报)   │
        │  assignment_id 隔离    │
        └────────────────────────┘
```

## 2. 单个 Task 的认知循环

```
┌─────────────────────────────────────────────────────────────┐
│  1. 初始化：创建 objective 节点                              │
│     task.id → wm_node (kind=objective)                     │
└────────────────────┬────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────────┐
│  2. PlannerAgent：观察状态 + 生成计划                        │
│     - 调用 observe_state 工具（读取世界模型）                │
│     - 调用 propose_moves 工具（生成新 Move）                │
│     - 写入：wm_node (kind=move, state=open)                │
└────────────────────┬────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────────┐
│  3. ExecutionLoop：轮询 + 调度                              │
│     - 查询：SELECT * FROM wm_node                          │
│              WHERE task_id=? AND kind='move'               │
│              AND state='open'                              │
│     - 依赖检查：depends_on 字段拓扑排序                      │
│     - 状态转换：state: open → running                       │
└────────────────────┬────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────────┐
│  4. Executor：执行 Move                                     │
│     - 构建 actor.Move (instruction, complexity)            │
│     - 调用 LLM Agent (eino 框架)                           │
│     - 工具调用：scan_web/exploit/write_lead/...            │
│     - 产出 Attempt（待验证的发现）                           │
└────────────────────┬────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────────┐
│  5. 写入 Observation                                        │
│     - wm_node (kind=observation, confidence=unverified)    │
│     - wm_edge (move --produces--> observation)             │
└────────────────────┬────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────────┐
│  6. Verifier：复现验证                                       │
│     - Replay primitives（回放 L1 原语）                     │
│     - wm_verification (记录验证结果)                        │
│     - confirmed: 晋升为 discovery                           │
│     - refuted: 不进图（证据留档）                            │
└────────────────────┬────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────────┐
│  7. 晋升 Discovery                                          │
│     - wm_node (kind=discovery, confidence=verified)        │
│     - wm_edge (observation --supports--> discovery)        │
└────────────────────┬────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────────┐
│  8. Move 完成                                               │
│     - state: running → done                                │
│     - completed_at: now()                                  │
└────────────────────┬────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────────┐
│  9. EventBus 触发事件                                        │
│     - PublishMoveCompleted(task_id, move_id)               │
│     - PublishVerificationPassed(task_id, node_id)          │
└────────────────────┬────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────────┐
│  10. PlannerAgent 重新规划                                   │
│      - 订阅事件唤醒                                          │
│      - observe_state（读取最新状态）                         │
│      - evaluate_progress（评估是否达成目标）                 │
│      - propose_moves（生成下一步计划）                       │
└────────────────────┬────────────────────────────────────────┘
                     ↓
                  循环到步骤 3
```

## 3. Lead 黑板数据流

```
┌─────────────────────────────────────────────────────────────┐
│  Task A (executor-1)                                        │
│  调用工具：write_lead(kind="clue", detail="发现 /admin")     │
└────────────────────┬────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────────┐
│  write_lead 工具执行                                         │
│  1. 查询 task.assignment_id                                 │
│  2. 写入 lead 表：                                           │
│     INSERT INTO lead (assignment_id, kind, detail, ...)    │
│     VALUES ('assignment-123', 'clue', '发现 /admin', ...)  │
└────────────────────┬────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────────┐
│  Lead 黑板 (PostgreSQL)                                     │
│  assignment-123:                                            │
│  ├─ clue: "发现 /admin" (source: task-A)                   │
│  ├─ observation: "确认无鉴权" (source: task-A)              │
│  └─ deadend: "/api/v1 全 404" (source: task-B)             │
└────────────────────┬────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────────┐
│  Task B (executor-2)                                        │
│  构建 Prompt：loadLeadForPrompt(assignmentID)               │
│  ├─ 读取：lead.List(assignment-123)                         │
│  └─ 注入：System Prompt 情报黑板段                          │
│            "已知线索：发现 /admin..."                        │
└─────────────────────────────────────────────────────────────┘
```

## 4. 世界模型查询流

```
┌─────────────────────────────────────────────────────────────┐
│  前端：GET /attack_graph/:task_id                           │
└────────────────────┬────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────────┐
│  API Handler                                                │
│  1. 查询 task.assignment_id                                 │
│  2. 读取节点（4 种 kind）：                                  │
│     SELECT * FROM wm_node                                   │
│     WHERE task_id=? AND kind IN (...)                      │
│  3. 读取边：                                                 │
│     SELECT * FROM wm_edge                                   │
│     WHERE task_id=?                                         │
└────────────────────┬────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────────┐
│  返回 JSON                                                   │
│  {                                                          │
│    "nodes": [                                               │
│      {"id": "obj-1", "kind": "objective", ...},            │
│      {"id": "move-1", "kind": "move", "state": "done"},    │
│      {"id": "obs-1", "kind": "observation", ...},          │
│      {"id": "disc-1", "kind": "discovery", ...}            │
│    ],                                                       │
│    "edges": [                                               │
│      {"source": "move-1", "rel": "produces", "target": "obs-1"},│
│      {"source": "obs-1", "rel": "supports", "target": "disc-1"}│
│    ]                                                        │
│  }                                                          │
└─────────────────────────────────────────────────────────────┘
```

## 5. Complexity → Profile 路由

```
┌─────────────────────────────────────────────────────────────┐
│  worldmodel.Node (kind=move)                                │
│  ├─ complexity: "moderate"                                  │
│  └─ content: {"instruction": "扫描目标端点"}                 │
└────────────────────┬────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────────┐
│  nodeToActorMove()                                          │
│  actor.Move {                                               │
│    Instruction: "扫描目标端点",                              │
│    Complexity: ComplexityModerate                           │
│  }                                                          │
└────────────────────┬────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────────┐
│  dispatcher.For(complexity)                                 │
│  查找注册的 Profile：                                        │
│  profiles[ComplexityModerate] → moderateProfile             │
└────────────────────┬────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────────┐
│  moderateProfile()                                          │
│  Profile {                                                  │
│    MaxSteps: 30,                                            │
│    MaxTokens: 50000,                                        │
│    Tools: [scan_web, exploit, write_lead, ...],            │
│    Timeout: 20min                                           │
│  }                                                          │
└────────────────────┬────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────────┐
│  Executor 执行                                               │
│  - LLM 调用（通过 router.For(complexity) 获取模型）          │
│  - 工具调用（受 Tools 白名单限制）                            │
│  - 步数控制（MaxSteps 预算）                                 │
└─────────────────────────────────────────────────────────────┘
```

## 6. 隔离边界示意

```
┌─────────────────────────────────────────────────────────────┐
│  Assignment: assignment-123 (租户隔离)                       │
├─────────────────────────────────────────────────────────────┤
│  Lead 黑板 (PostgreSQL)                                     │
│  ├─ assignment_id = 'assignment-123'                       │
│  ├─ clue: "线索1" (source: task-A)                         │
│  ├─ observation: "发现1" (source: task-B)                  │
│  └─ deadend: "死路1" (source: task-C)                      │
├─────────────────────────────────────────────────────────────┤
│  Task A: task-a (世界模型隔离)                               │
│  ├─ wm_node (task_id='task-a')                             │
│  │  ├─ objective: "测试 http://a.com"                      │
│  │  ├─ move-1: "扫描端点" (state=done)                     │
│  │  ├─ observation-1: "发现 /admin" (confidence=verified) │
│  │  └─ discovery-1: "未授权访问" (confidence=verified)     │
│  └─ wm_edge (task_id='task-a')                             │
│     ├─ move-1 --produces--> observation-1                  │
│     └─ observation-1 --supports--> discovery-1             │
├─────────────────────────────────────────────────────────────┤
│  Task B: task-b (世界模型隔离)                               │
│  ├─ wm_node (task_id='task-b')                             │
│  │  ├─ objective: "测试 http://b.com"                      │
│  │  └─ move-1: "扫描端点" (state=open)                     │
│  └─ wm_edge (task_id='task-b')                             │
│     └─ (空)                                                 │
└─────────────────────────────────────────────────────────────┘

不同 Assignment 完全隔离
┌─────────────────────────────────────────────────────────────┐
│  Assignment: assignment-456 (另一个租户)                     │
│  ├─ Lead 黑板（独立）                                        │
│  ├─ Task X（独立世界模型）                                   │
│  └─ Task Y（独立世界模型）                                   │
└─────────────────────────────────────────────────────────────┘
```

## 7. 事件驱动流程

```
┌─────────────────────────────────────────────────────────────┐
│  ExecutionLoop                                              │
│  Move 完成：state → done                                     │
└────────────────────┬────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────────┐
│  EventBus.PublishMoveCompleted(task_id, move_id)           │
└────────────────────┬────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────────┐
│  PlannerAgent (订阅者)                                       │
│  收到事件 → 唤醒 → 重新规划                                  │
└────────────────────┬────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────────┐
│  observe_state 工具                                          │
│  读取世界模型最新状态                                         │
└────────────────────┬────────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────────┐
│  evaluate_progress 工具                                      │
│  评估是否达成目标                                             │
└────────────────────┬────────────────────────────────────────┘
                     ↓
        ┌────────────┴────────────┐
        │                         │
        ↓                         ↓
┌──────────────┐         ┌──────────────┐
│  目标达成     │         │  继续规划     │
│  退出循环     │         │  propose_moves│
└──────────────┘         └───────┬───────┘
                                 ↓
                 创建新 Move（循环继续）
```

## 📖 图例说明

- **实线箭头 (→)**: 数据流方向
- **虚线箭头 (⇢)**: 事件流/消息流
- **方框 (┌─┐)**: 组件/模块
- **双线框 (╔═╗)**: 存储层（数据库/缓存）

---

## 🔍 关键路径

1. **认知循环**: objective → move → execution → observation → discovery → 循环
2. **情报共享**: Task A → Lead 黑板 → Task B（跨 task 情报同步）
3. **隔离边界**: Assignment（租户隔离）→ Task（世界模型隔离）
4. **事件驱动**: Move 完成 → EventBus → PlannerAgent 重规划
