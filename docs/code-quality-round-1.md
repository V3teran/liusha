### 2. 重复代码（中等）

发现多个重复的函数签名和结构体名称：

```go
// 重复的结构体名
type Agent struct {}        // 在多个包中重复
type AgentConfig struct {}  // 在多个包中重复
type Config struct {}       // 在多个包中重复
type Client struct {}       // 在多个包中重复
type Deps struct {}         // 在多个包中重复
```

**问题分析**：
- ✅ 这些在不同包中是合理的（不同的 Agent 实现）
- ⚠️ 但命名过于通用，容易混淆
- ⚠️ `Config` 这个名字在配置包中重复过多

**建议**：
1. 通用结构体加上包前缀：`ExecutorAgent`, `PlannerAgent`
2. `Config` 改为更具体的名字：`LLMConfig`, `ToolConfig`

**优先级**: P2
